# Macro Recorder 1.2.0

Macro Recorder 是一个基于 Java 的 Windows 键鼠宏录制与播放工具。它支持键鼠动作录制、横向动作时间线、循环播放、暂停与停止，以及基于 OpenCV 的图像识别流程节点。界面使用 Swing 和统一的深色主题，文件与目录选择使用 Windows 原生文件面板。

当前软件版本为 **1.2.0**，以 [`ApplicationInfo.APP_VERSION`](src/main/java/com/macro/constant/ApplicationInfo.java) 为准，由维护者决定升级；[`pom.xml`](pom.xml) 的 Maven 数字版本与其同步，数字版本一致时保留已有后缀。`.mr` 文件格式版本由 `MacroFormat` 独立维护，不随软件版本变更。近期变化见 [更新日志](CHANGELOG.md)，项目状态和文档入口见 [项目状态索引](docs/README.md)。

## 主要功能

- **录制**：鼠标移动、左/中/右键按下/释放、滚轮、键盘按下/释放；支持设置鼠标移动采样间隔及指定目标窗口；X1/X2 侧键不提供编辑入口，录制时忽略。
- **录制控制栏**：主窗口切换为自绘双行操作栏，提供目标信息、截图、暂停/继续、终止和自绘最小化；保留 DWM 外框、水平缩放、固定高度、位置与宽度记忆及录制置顶，停止后恢复完整窗口。原有开始录制自动最小化设置继续生效。
- **播放**：指定循环次数或无限循环，暂停、继续、停止；停止和异常结束时释放已按下的键鼠。
- **时间线**：横向滚动查看动作、拖动卡片调整顺序、选中节点、双击编辑、右键插入/删除、Delete 删除；拖动有半透明影像和落位预览，指定跳转随目标节点移动。支持坐标/延迟行内编辑、动态操作编号，以及按真实目标 ID 绘制的远距离水平入卡分支线。图像卡片右上角用黄色三角提示模板质量问题，悬浮可查看原因。
- **动作编辑**：在同一个编辑器中插入或编辑动作类型和属性，键盘代码由按键名称生成且只读。
- **图像采集**：框选截图、取消选区、预览、剪贴板图片粘贴、图片拖入、保存 PNG 及另存为。
- **图像识别**：向时间线插入图像识别节点，配置模板 PNG、匹配阈值、可选缩放匹配、重试延迟及成功/失败行为；成功后可中心或范围内随机单击，失败后可单击独立指定的屏幕坐标，再继续后续动作或终止任务。
- **按位置优先识别**：播放到识图节点时，先搜索上次命中位置附近；失败后同时扩大局扫和全扫，先命中的结果返回。位置只记在内存，加载 MR 不触发扫描。
- **离线文字提取**：在采集图像页提取简繁中文、英文、日文、韩文，可编辑、复制及保存 TXT。
- **识别测试窗口**：从图像识别动作中打开，载入当前模板、阈值及缩放开关，使用 OpenCV 观察相似度、位置、多结果、耗时及内存统计；测试不会发送点击。
- **录制中图像操作**：录制时临时框选模板并生成图像识别节点，采集交互不录入普通动作；排除采集耗时，并按录制设置补充鼠标移动桥接。
- **指定窗口截图**：采集图像页可独立指定窗口，截图时尝试恢复并前置窗口，只允许在高亮内容区内框选，鼠标自由移动；可切回屏幕截图。
- **窗口内识别**：图像动作可将搜索范围限定为指定窗口内容区，窗口移动或调整大小后按新范围搜索；设置随 MR 保存，不在识别时激活窗口。
- **设置与提示**：默认保存目录、采样及窗口最小化/恢复设置，统一深色控件和可展开异常详情的提示。

## 技术栈与环境要求

| 项目 | 使用内容 |
|---|---|
| 操作系统 | Windows 11；当前原生窗口及文件面板实现面向 Windows |
| Java | **JDK 17**，构建与打包需要完整 JDK |
| 构建 | Maven；同时保留 Maven Wrapper |
| 界面 | Swing、自绘组件、统一 `ThemeManager` / `ThemePalette`；项目包含 FlatLaf 依赖 |
| 全局键鼠事件 | JNativeHook |
| Windows 接口 | JNA / JNA Platform |
| 图像匹配 | OpenCV（OpenPnP Java 绑定及本机库） |
| 数据与代码生成 | Jackson、Lombok |
| 图片导入 | Java ImageIO、TwelveMonkeys WebP 支持 |

首次构建需要联网下载 Maven/依赖；首次使用 Wrapper 时还需要下载其指定的 Maven 分发包。IDE 运行时请启用 Lombok 注解处理。

## 构建与启动

以下命令在项目根目录的 PowerShell 中执行。

### 编译与打包

已有 Maven 时：

```powershell
mvn -q -DskipTests compile
mvn -q -DskipTests package
```

也可以使用仓库中的 Wrapper，无需预先安装 Maven：

```powershell
.\mvnw.cmd -q -DskipTests package
```

`mvnw`、`mvnw.cmd` 和 `.mvn/wrapper/maven-wrapper.properties` 是正式构建文件，需一并保留。当前 Wrapper 为 `only-script` 模式，不需要额外提交 Wrapper JAR。

打包生成 `target/recorder-<Maven版本>.jar` 和 `target/lib/` 依赖目录。该 JAR 不是包含全部依赖的单文件发行包。

### 从源码启动

完成 `package` 后：

```powershell
java -cp "target/classes;target/lib/*" com.macro.MacroApplication
```

也可在 IDE 中运行 `com.macro.MacroApplication.main()`。普通启动会在后台预加载 OpenCV。

### Windows 应用打包

环境中需要可用的 `mvn`、Windows 64 位 JDK 17 和 PowerShell。优先使用 `JAVA_HOME` 指定的 JDK：

```powershell
.\build.bat
# 在终端或自动化环境中取消脚本结束时的暂停：
.\build.bat --no-pause
```

需要 EXE 安装包时，在构建电脑安装 Inno Setup 6.6+ 或 7，然后运行：

```powershell
.\build-installer.bat
.\build-installer.bat --no-pause
```

两个入口共用精简构建流程：`build.bat` 生成 ZIP，`build-installer.bat` 同时生成 ZIP 和 `MacroRecorder-<Maven版本>-Setup.exe`。脚本从 PATH、常见位置和安装记录查找 Inno Setup；自定义位置也可通过环境变量 `INNO_SETUP_COMPILER` 指定 `ISCC.exe` 的完整路径。安装版使用中文深色向导，默认安装到当前用户的 `%LOCALAPPDATA%\Programs\Macro Recorder`，无需管理员权限，提供开始菜单入口、可选桌面快捷方式和卸载入口。升级和卸载前会检查应用是否仍在运行，不自动强制关闭；配置、宏和截图由程序自行创建，安装器不收录或清理这些个人数据。

脚本保留完整 Maven 构建输出，不执行 `clean`，也不运行 Maven 测试。打包时只收集主程序和运行依赖，OpenCV 仅保留 Windows 64 位库，并自动分析 Java 模块、生成压缩后的运行环境。随后使用发行包自带的 Java 执行 9 项检查，包含界面依赖、本机库、JSON、图片插件、合成图像识别和离线 OCR；检查失败会停止打包。既有发行包的 8 项检查记录属于增加 OCR 之前，不能代替当前源码的打包验收。

每次构建使用独立目录，最后压缩为：

```text
dist/build-<时间戳>-<唯一标识>/
├── MacroRecorder/
│   └── MacroRecorder.exe
├── MacroRecorder <Maven版本>.zip
├── MacroRecorder-<Maven版本>-Setup.exe（仅安装包入口生成）
└── build-info.json
```

构建结束会显示准确路径与体积；`build-info.json` 记录版本、Java 模块和基础检查结果。旧发行包、个人数据和已有诊断产物均不会被清理或覆盖，本次中间文件保存在 `target/package-<时间戳>-<唯一标识>/`。发行包仅支持 Windows 64 位，使用时保留完整应用目录，启动其中的 `MacroRecorder.exe`。基础检查不替代自动化回归测试和真实桌面验收。

## 基本使用

1. 点击“开始录制”，或先“指定窗口开始”，再操作目标程序。
2. 录制完成后按 **F12** 停止。
3. 点击当前宏卡片底部的动作/节点数量区域进入时间线，检查或编辑动作。
4. 设置播放循环次数或勾选无限循环，点击“播放”。
5. 播放时可按 **F11** 暂停/继续，按 **F12** 停止。

录制期间按 **F10** 或点击“图像操作”进入冻结截图选区；确认后恢复录制，取消则放弃本次采集。截图选区支持 **Esc** 取消。F12 在采集期间仍用于停止录制。

进入录制截图前，若鼠标左、中、右键仍处于按下状态，会先自动松开，再冻结画面。已录入的按下动作仍补齐配对释放，自动松开及随后重复的释放不会多录节点；再次正常按下后继续录制点击。暂停中截图也会松开鼠标，完成或取消后保持暂停；取消截图不会重新按住鼠标。释放失败时本次截图取消并提示手动松开后重试。该行为仅用于录制截图，普通采集页截图及普通暂停沿用原行为。

指定目标窗口用于定位窗口级操作；浏览器标签页不是独立窗口。录制和播放会向真实桌面发送输入，请先用简单动作确认目标及坐标。

## 宏文件与个人配置

- 默认宏目录为程序目录下的 **`save/`**；可在设置中修改。
- “保存 MR”用于保存当前宏，已有文件时沿用当前文件；“另存为”选择新位置。文件名会按现有规则补充 `.mr`。
- 非空流程在任何写入前校验；删除跳转目标后保存会报错，不能覆盖原有效文件，也不会自动改到其他节点。非空但缺失的模板路径仍可存储；侧键按下/释放数据在保存、加载及播放前拒绝。
- “加载 MR”读取普通动作及流程节点；默认可以在启动时加载上次使用的宏，此选项可在设置中关闭。
- `.mr` 使用 JSON，保存动作、目标窗口和可选流程图。格式版本与软件版本分别维护；不支持的格式会提示版本不兼容。
- 图像节点保存**模板文件路径引用和匹配参数**，不内嵌 PNG/Base64。相对模板路径以 MR 文件所在目录解析。移动或分享宏时，需同时保留模板文件及对应路径关系；旧版仅包含普通动作的 MR 仍可加载。
- `config.properties` 保存个人目录、上次宏路径和运行设置，首次启动会自动创建，无需预先提供。可选示例见 [`config.example.properties`](config.example.properties)。
- 默认截图目录为程序目录下的 **`ScreenCapture/`**，也可在设置中修改。

MR 加载后，动作和流程保存在内存中，移走 MR 本身通常不影响当前播放，但程序仍记着原路径。模板图片没有为整次播放建立独立快照：播放前检查全部引用，每次识别也会检查模板文件是否存在，即使之前已有缓存。播放中移走图片，下一次识别可能终止播放并提示模板缺失，不会走普通“未找到”分支；已经读入图片的那一次识别可以完成。移动或整理文件前应先停止播放。

开发运行时，程序目录通常是项目根目录；jpackage 发行包使用 EXE 所在目录。以上个人文件、构建产物与诊断截图均由 `.gitignore` 排除，仓库不包含你的实际配置、宏或截图素材。

## 错误报告

发生错误时，保留原有弹窗或状态提示，并在**程序根目录的 `log/`** 自动创建 UTF-8 错误报告，文件名为 `error-yyyyMMdd-HHmmss-SSS-唯一编号.log`。其中 `yyyyMMdd` 为年月日、`HHmmss` 为时分秒、`SSS` 为毫秒；末尾唯一编号避免同一毫秒内多次报错重名覆盖。开发运行时对应项目根目录，发行包对应 EXE 所在目录；每次错误独立保存，不覆盖或自动清理旧报告。

报告包含程序版本、时间、记录线程、错误描述、完整异常堆栈及原因链，以及操作系统和 Windows 构建版本、Java 版本与架构、CPU 型号和可用处理器数量、物理内存/JVM 内存采样、显示器区域、显示模式与缩放。个别环境字段采集失败不影响记录原错误；没有异常对象的错误消息会明确记录调用位置。

覆盖统一错误弹窗、带异常的操作警告、MR/配置读写失败、文字提取失败、部分输入释放及窗口恢复异常，以及启动后未捕获的界面/后台线程异常。普通提示、输入校验警告和正常取消不生成错误报告。报告不自动上传，不附带截图、宏或配置原文；错误描述及堆栈可能包含相关文件路径。

目录不可写时保留原错误处理，并回退输出到标准错误流，不自动改存其他目录。强制结束进程、断电及直接终止 JVM 的原生崩溃不保证能生成此类报告。

## 图像识别流程

### 采集模板

在主页点击“采集图像”，点击“截图”框选目标，确认后保存为 PNG。也可以粘贴剪贴板中的图片或拖入支持的图像；普通文本不会作为图片采集。

选择“指定窗口”可从列表选择截图目标，确认后返回采集页；此时不激活目标。点击“截图”才隐藏本程序的可见窗口，尝试恢复并前置目标，再采集冻结画面。高亮范围为目标的窗口内容区，选框拖出边界会自动截断，窗口外不能开始框选，鼠标不会被限制在窗口内；Enter、双击或“完成”确认，Esc、右键或关闭取消。选择“使用屏幕”恢复鼠标所在屏幕的原截图方式。

指定窗口只记在当前采集页内存中，不写入 MR 或配置，不改变录制窗口、F10 录制截图或播放识别范围。目标关闭、身份变化、无法前置或截图期间位置/大小变化时，本次失败并恢复本程序，保留已有图片，不自动换到其他窗口。它截取的是前置后的可见屏幕画面，不是后台窗口渲染；其他置顶窗口遮挡仍需先移开。系统标题栏和边框不属于内容区，自绘标题栏可能属于内容区。

沿用单屏冻结框选：窗口跨屏或部分在屏幕外时，选择内容区可见面积最大的屏幕，只允许选择该屏上的可见内容，冻结层会明确提示；要截取完整窗口请先移入单屏。DPI 换算使用物理客户区与实际截图像素，向内取整，边缘可能少一两个像素。实现、验证边界见 [指定窗口截图](docs/window-capture.md)。

### 提取图片文字

采集图像页有图片后，点击“提取文字”，选择简体中文、繁体中文、英语、日语或韩语，再点击弹窗中的“提取文字”。默认勾选简体中文和英语；图片只有一行时可勾选“单行文字”。结果可直接编辑、复制，或保存为 UTF-8 TXT；取消或关闭窗口会请求停止提取。

识别在本机离线进行，不上传图片，不自动下载语言包。它只提取文字，不分析语义，也不新增文字判断或点击流程。组件和五种语言资源随程序分发，首次使用展开到程序目录的 `ocr-cache/`；资源原始大小约 19.5 MiB，单独 ZIP 压缩约 11.0 MiB，首次展开另占约 19.5 MiB，不能直接当成安装包最终增量。详细使用、缓存与第三方许可见 [离线 OCR](docs/offline-ocr.md)。

### 查找节点

在时间线点击“查找节点”或按 **Ctrl+F** 打开查找栏。输入编号可精确定位当前第几项，例如 `12`、`012` 或 `#12`；文字可查动作类型、按键名称和模板图片名，忽略大小写，支持用空格组合条件，例如“鼠标 左键”“键盘 A”“图片 login”。单个英文字母按独立名称匹配；查找只用当前节点参数，不读取图片或执行识别。

输入后自动定位到匹配卡片，当前结果显示金黄色外框，并显示结果序号和总数。**Enter／F3** 下一项，**Shift+Enter／Shift+F3** 上一项，到末项后循环；也可点击查找栏按钮。没有结果时显示“无匹配”，时间线仍保留全部节点。

查找保留原来的选择和多选，不改动作、延迟、分支或撤销历史；录制、播放和暂停查看时也能使用。**Esc** 优先关闭查找，保留原选择；关闭后重开保留查询，切换或重新加载宏时清空。插入、删除、编辑、拖动及撤销后更新结果和编号，刷新本身不抢滚动位置。查找框内的复制、粘贴、全选和删除仍只处理文字。

### 多选与批量编辑

在时间线按 **Ctrl+单击** 切换节点选择，按 **Shift+单击** 从最近一次点击位置连续选择，Ctrl+Shift 可追加区间；**Ctrl+A** 全选可见节点，Esc 或点击轨道空白取消选择。普通单击改为只选该节点；按住已选卡片开始拖动时保留整组选择。坐标区域也支持带 Ctrl／Shift 的选择，普通单击仍编辑坐标。

选择两个以上节点后，上方显示选中数量及“批量编辑”“删除所选”“取消选择”。批量编辑仅修改勾选的项目：普通动作延迟、具有重试行为的图像节点重试间隔，均以毫秒填写，支持 0；不适用的项目禁用。没有可修改延迟的图像组合仍可移动、复制或删除。整批修改、删除、移动或粘贴各占一步撤销，Ctrl+Z 同时恢复原来的多选。

拖动任一选中卡片可移动整组；不连续的节点按原先顺序聚到释放位置，影像显示数量，轨道预览整组占位。指定跳转随原节点 ID 保留，动作延迟随节点移动。Delete 或右键“删除所选”只确认一次，不合并被删动作的延迟；删除被引用目标时提示跳转将失效，需要重新指定或撤销。录制、播放及暂停时可多选与复制，批量修改、移动、删除和粘贴锁定。

### 复制／粘贴节点

选中时间线节点后按 **Ctrl+C** 或右键“复制节点”，再选中位置按 **Ctrl+V**：副本固定插入到该节点后，无选中节点时追加到末尾，不受“插入动作”的默认方向设置影响。支持普通动作和图像识别节点，复制当时的参数快照；每次粘贴创建新 ID，后续修改副本不影响来源或其他副本。粘贴作为一步修改，可用 Ctrl+Z 撤销；复制不修改流程或占用撤销步骤。

图像节点保留模板、阈值、缩放开关、点击、窗口范围和成功/失败配置。指定跳转继续指向原目标 ID；如果当前宏找不到该目标，提示并拒绝粘贴，不自动改指其他节点。重试指向副本自身，继续执行按粘贴后的顺序连接，终止使用当前宏终点。跨宏粘贴时，相对模板路径转换为来源图片的实际路径，避免误用目标目录里的同名图片；**复制的是图片引用，不搬移图片文件，原模板仍需保留**。

多选时 Ctrl+C 或右键“复制所选”复制整组，Ctrl+V 按原顺序插入到最近选中的节点后，无选择时追加；副本整体保持选中。整组内部的指定跳转改指对应副本，组外跳转仍指原目标，外部目标缺失时整组拒绝粘贴。单节点复制仍保留原指定目标。剪贴板节点总内容限制为 1 MiB。

节点数据与可读文字摘要同时放入剪贴板，因此在普通文本框粘贴仍可得到节点信息。复制其他文字或图片后，原节点不再可粘贴；普通文字、图片或文字形式的 JSON 不会被当作节点。文字输入框内的 Ctrl+C／Ctrl+V 保持文字编辑行为；录制、播放及暂停查看期间禁止粘贴，但仍允许复制当前节点。剪贴板被占用或内容无效时提示，不修改当前流程。

### 撤销时间线修改

节点右键菜单采用四宫格：上排为编辑、插入，下排为复制节点、删除，底部并排提供粘贴（Ctrl+V）和撤销（Ctrl+Z）。删除项用红色区分；播放查看时复制仍可用，其余编辑操作禁用。空白轨道右键提供插入、粘贴与撤销。

空闲时，在时间线选中节点或点击轨道后按 **Ctrl+Z**，撤销最近一次确认的编辑；右键菜单也提供“撤销”。支持插入、删除、拖动排序、编辑动作参数、坐标与延迟行内修改，以及待机头开关和延迟；一并恢复节点顺序、编号、分支目标及删除时转移的延迟。取消、无效输入和没有实际变化的编辑不占用撤销步骤。文字输入框中的 Ctrl+Z 不触发整个时间线撤销。

撤销历史只存在内存中，最多保留 100 步，并以约 32 MiB 的序列化快照限制较早记录；单个宏超过此预算时仍保留最近一步。不保存模板图片、不写入 MR。录制、播放和暂停查看期间不可撤销；停止后仍可使用当前宏的历史。加载其他宏、开始新录制、跨目录另存为会清空历史，同目录保存保留历史。撤销本身不自动保存到磁盘，恢复后仍需手动保存；旧编辑窗口会关闭，避免过时内容写回。

### 时间线拖动排序

仅与图像识别有关的相邻连线在上方显示“执行”或图像分支条件，普通动作之间只显示等待时间和箭头。进入图像识别节点的“检查”占位文字已改为实际分支等待，通常为 `0 ms`；图像节点下方回路上的时间表示重试间隔，两者分开显示。

空闲时，左键按住普通动作或图像识别卡片，移动一小段距离开始拖动。半透明、略微虚化的卡片影像保留按下位置并跟随鼠标；轨道中显示插入标记及占位框，其他卡片让位。靠近左右边缘会自动滚动，可以移动到视口之外的节点附近。

在轨道可见区域松手完成排序，编号及连线随之刷新；按 Esc、移出轨道区域松手、窗口失去激活或隐藏则取消。拖动预览不改动实际流程，未移动到其他位置时不产生修改。头部待机卡固定，录制、播放和暂停查看期间不能拖动；单击坐标仍直接编辑，双击和右键菜单保留。

指定跳转按节点身份保留。例如原来 **3→5**，将目标卡片从第 5 项移到第 7 项后，变为 **3→7**；多个指向同一节点的跳转也一起跟随。普通继续执行按新顺序连接，重试保持自身，终止仍结束任务；动作延迟随节点移动。保存并重新加载 MR 后保留新顺序及原目标，不改变文件格式。更多说明见 [图像分支与时间线](docs/image-branch-jumps.md#拖动排序)。

### 插入识别节点

1. 进入动作时间线，右键节点选择“插入动作”，新节点插在选中节点之前。
2. 选择“图像识别”，指定有效的模板 PNG，并设置匹配阈值和重试延迟。
3. 分别配置“成功行为”和“失败行为”，保存后播放宏。

### 窗口内识别

在“编辑动作 → 图像识别”中，将“识别范围”从“桌面”切换为“指定窗口”，点击“识别窗口”选择目标，再保存。预览识别使用同一份未保存范围配置；桌面模式和旧 MR 保持原有行为。

窗口模式下，局扫、扩大局扫及最后的完整搜索都限定在目标当前客户区，窗口外出现相同图片也不会被搜索。窗口移动、调整大小或跨屏后重新读取当前范围，旧位置提示随范围变化失效，再在窗口内定位；不会改扫桌面。跨屏窗口逐屏检查可见内容，不拼接跨越屏幕接缝的模板。

这一版仍匹配可见画面，**目标必须保持在前台且未最小化**；识别不会自动前置或恢复窗口，置顶遮挡仍需移开。目标关闭、失去前台、无法唯一定位或识别期间位置/大小变化时会明确报错并结束本次播放，不走普通“图片未找到”分支。窗口有效但图片不存在时，才执行配置的失败行为。

窗口描述（进程名、标题和窗口类）保存在 MR 中，另存为保留；不保存 HWND、PID 或坐标。优先唯一标题匹配，标题变化后只有进程名和窗口类候选唯一时才回退；同一次播放绑定后不自动换窗，重新播放时重新定位。加载 MR 和播放预检只检查配置及模板，不枚举窗口或提前扫描。该设置与采集页的截图窗口、宏的录制/播放目标分别配置。非整数 DPI 的边缘向内取整，贴边或整窗模板建议留少量边距。详细边界见 [窗口内识别](docs/window-recognition.md)。

| 行为 | 执行结果 |
|---|---|
| 重试 | 等待重试延迟后，重新识别当前节点；支持暂停、继续和停止 |
| 执行 | 继续执行时间线中的下一个节点 |
| 终止 | 结束整个宏播放任务，包括无限循环 |
| 点击后执行 | 成功时单击本次最佳命中范围，失败时单击独立指定的屏幕坐标，再继续后续动作 |
| 点击后终止 | 成功时单击本次最佳命中范围，失败时单击独立指定的屏幕坐标，再结束整个任务，包括无限循环 |
| 跳转到指定节点 | 从当前时间线选择前方或后方目标；成功/失败独立配置，仅选择跳转时显示对应目标菜单 |

旧宏缺少行为配置时，默认**成功执行、失败重试**；缺少点击方式时默认中心点击。时间线显示主链、自回路、终止标记及指定跳转连线；操作编号只用于展示，不能代替节点 ID。含点击行为或 JUMP 的新宏需要支持相应行为的应用版本。实现细节见 [图像分支与时间线](docs/image-branch-jumps.md)。

正式播放的 `IMAGE_CHECK` 通过 `OpenCvImageMatcher` 调用现有屏幕捕获和 OpenCV 模板匹配实现，结果保留相似度与匹配矩形。普通键鼠动作仍由 `MacroAction` 执行；识别节点不会被混入底层输入动作类型。

### 点击命中区域

在“成功行为”中选择“点击后执行”或“点击后终止”，即可编辑“点击方式”：

| 点击方式 | 选点规则 |
|---|---|
| 中心点击（默认） | 单击本次最佳命中区域的中心 |
| 范围内随机点击 | 每次在本次最佳命中区域内重新取一个位置，单击一次 |

两种方式都使用鼠标左键；多处命中时只使用首个成功搜索阶段中相似度最高的一处，不逐个点击所有结果。开启缩放匹配时，成功点击范围跟随实际命中的大小。缓存中的旧命中坐标仅作为搜索提示，不直接用于点击。

成功和失败行为菜单提供相同选项。在“失败行为”选择“点击后执行”或“点击后终止”后，填写独立的“失败点击 X”和“失败点击 Y”；两个值都必须明确填写，允许 `0` 和负坐标。未找到图像时在该固定屏幕逻辑坐标执行一次左键单击，不使用上次命中位置，也不使用成功分支的中心/随机点击方式。坐标不随识别窗口移动；缺少任一坐标时不能保存或播放。识别出错仍按原异常处理，不触发失败点击。

动作编辑器按当前选项显示相关字段，其他字段连同名称一起隐藏：成功/失败选择跳转时才显示各自目标；成功点击时才显示“点击方式”；失败点击时才显示 X/Y；任一行为选择重试才显示重试延迟；识别范围选择指定窗口才显示窗口按钮。编辑过程中隐藏不清空已选目标、点击方式、坐标或窗口描述，切回选项后恢复；整排隐藏时收拢布局，成功/失败及 X/Y 保持左右对应。

两个行为菜单都将“跳转到指定节点”固定在最后，以后新增选项也遵循这一顺序。设置随 MR 保存、加载和另存为保留，旧宏仍默认成功执行、失败重试。两种行为都不使用重试时，隐藏的重试框临时空值不会阻止保存，沿用此前合法值；切回重试后仍要求合法的非负延迟。

点击后执行仍完整等待后续动作原有间隔；点击后终止结束整个任务，包括无限循环。暂停或停止会在移动前、按下前及完整点击后检查；鼠标已按下时先释放，再处理暂停或停止。

### 按位置优先识别

正式播放执行到图像识别节点时才截图，不在加载 MR 或开始播放时提前扫描所有节点。位置仅保存在当前 MR 会话的内存中，不写入 MR：录制中框选的模板可用选区坐标作为初始提示；加载 MR 后没有位置提示，首次执行该节点时完整搜索所选范围，命中后缓存实际矩形。后续循环和再次播放优先使用最新位置，重新加载 MR 或开始新录制时清空。

| 阶段 | 搜索范围（逻辑坐标） |
|---|---|
| 局扫 | 上次命中矩形，每侧增加 32 像素或对应边长的 25%，取较大值 |
| 扩大局扫 | 局扫未命中后，从同一命中矩形计算，每侧增加 96 像素或对应边长的 75%，取较大值 |
| 完整搜索 | 与扩大局扫同时开始；桌面模式搜索所有显示器，窗口模式仅搜索指定窗口内容区。没有位置提示时直接执行该阶段 |

局扫实际只截取与区域相交的屏幕部分。各阶段重新截图、完整检查该阶段范围，不排除先前检查过的位置；同一阶段的缩放比例复用截图。搜索范围按屏幕边界裁剪，覆盖范围重复或已等于所有屏幕的阶段不会重复执行。命中即结束本次搜索，以实际命中框更新位置，下次重新从局扫开始。更换模板、模板文件修改时间/大小变化、修改阈值或缩放开关，以及显示器布局或 DPI 变化时，旧位置失效。缓存有数量上限，淘汰后按首次执行处理。

局扫未命中后，扩大局扫和全扫竞速，先命中的阶段返回该阶段相似度最高的结果，并通知另一方停止；某一方先完成但未命中，仍等待另一方。两边都未命中时保留全扫的最佳候选。局扫成功仍优先于竞速，但竞速期间多个相同目标由先命中的阶段决定，不保证选择离旧位置最近或全屏相似度最高者。

单次截图或 OpenCV 原生调用内部无法强制中断，较慢的一方可能在结果返回后短暂收尾。后台任务数量受限；前次尚未收尾时，下一次识别回退到串行扩大局扫、全扫，避免不断积压。一次识别共用一份内存采样，后台任务退出后才关闭；进程采样仍包含其他线程，不能当成精确分配记录。竞速会增加瞬时计算和内存占用，不保证每次更快，也不能保证捕捉持续时间短于识别耗时的状态。独立测试窗口在当前所选范围内完整识别、展示多个结果，不使用或修改播放位置缓存。

### 可选缩放匹配

“允许缩放匹配”默认关闭。开启后，每个搜索阶段先在该阶段覆盖的屏幕区域按原尺寸搜索，全部未命中才尝试约 **66.7%～150%** 的有限比例，并在最佳候选附近细查。阶段内保留不同大小的目标及原有重复框合并规则；测试窗口在所选范围内完整搜索，实际播放先局扫、失败后竞速扩大局扫和全扫，两者共用缩放配置，旧宏缺少该字段时关闭。

缩放搜索复用本次截图和屏幕矩阵，大图在多核环境下每批最多计算两个比例，小图或单核环境串行处理；竞速中的扩大范围任务按比例串行，全扫保留双比例能力。缩放会增加耗时与临时内存；阶段内部的停止需等待当前批次原生调用结束，竞速调用方可先返回并让另一方后台收尾。识别耗时不抵扣后续动作间隔。合成测量条件与结果见 [自动测试记录](docs/automated-tests.md)。

### 模板质量提醒

图像卡片左上角仍显示编号；后台检查发现以下情况时，在右上角显示黄色感叹号三角，鼠标悬浮可展开原因和建议：

- 模板尺寸过小、可用于匹配的像素少或完全透明。
- 颜色几乎一致、纹理少或含明显重复纹理。
- 图片路径缺失、文件不存在或无法读取。

质量提醒不阻止录制、保存或播放；文件缺失或无法读取时，仍按原有播放校验和错误处理执行。更换模板、重建或重新显示时间线时会重新检查文件信息，不持续监控磁盘变化，提醒状态不写入 MR。

截取模板时，尽量包含稳定的图标、文字或边框，避免只截大片纯色背景或动态内容。该提醒是启发式检查，不能保证模板在屏幕中唯一，也不能通过提高阈值区分像素完全相同的图案。

### 独立测试窗口

在动作编辑窗口的“图像识别”属性中点击“识别”，打开独立测试窗口并载入当前模板、阈值、缩放开关及识别范围。按所选范围点击“识别当前屏幕”或“识别指定窗口”后，程序临时隐藏自身窗口，再使用 OpenCV 识别并恢复窗口；支持观察多结果、位置及性能数据，未达到阈值时显示未匹配提示。此窗口只测试匹配，不执行成功/失败行为，也不会发送点击。

窗口最小尺寸固定为 1080×640（逻辑像素），允许继续拉大；正文顶部仅保留识别范围。右侧“识别文字”在打开窗口或换图后自动提取**当前加载的模板图片**，支持简繁中文、英文、日文和韩文；无文字时显示“无信息”，有结果可点击“复制文字”。提取失败会显示提示，可重新提取；换图、清除和关闭会丢弃旧结果。文字提取不等待屏幕匹配，也不参与播放判断。

文字框采用深色圆角、柔和边框及统一滚动条；“无信息”水平和垂直居中，有文字时从左上方排版，可选择、换行和滚动查看。

匹配阈值右侧可启用缩放并分别设置下限和上限，默认约 **66.7%～150%**；下限支持 1%～100%，上限支持 100%～400%，最多三位小数。仍先按原尺寸搜索，再尝试范围内的有限比例，不保证遍历每个百分比。测试窗口中的修改不写回动作或 MR，实际播放仍使用动作的缩放开关和原有默认范围。

测试采集时会自动隐藏本程序窗口，实际播放则受播放设置、目标窗口激活和前台遮挡影响。两者参与匹配的画面可能不同，测试命中不保证播放时同样命中。

### 诊断

播放和测试路径保留识别诊断日志。可在 `java` 命令的 `-cp` 之前增加：

```text
-Dmacro.image.diagnostics.enabled=false
```

诊断截图默认关闭；仅排查时开启 `-Dmacro.image.diagnostics.capture=true`。默认输出到系统临时目录的 `MacroRecorder-image-diagnostics/`，可通过 `-Dmacro.image.diagnostics.directory=<目录>` 指定其他位置。诊断图片可能包含屏幕内容，不属于项目正式资源。

## Windows 原生文件面板

所有业务界面通过 `FileDialogService` 选择文件或目录。Windows 实现使用 JNA 接入 Shell Common Item Dialog：

- `IFileOpenDialog`：打开 MR、选择模板和测试图片；目录选择使用 `FOS_PICKFOLDERS`。
- `IFileSaveDialog`：保存新宏、另存为及截图另存为。
- 已有宏的直接保存、截图默认保存继续沿用各自原有逻辑。
- 取消、Esc 或关闭文件面板后，不执行后续文件操作。
- 文件面板外观和文件管理操作由 Windows 提供，不使用 Swing `JFileChooser`，也没有 Swing 回退策略。

接口、线程和人工验收范围见 [`docs/native-file-dialogs.md`](docs/native-file-dialogs.md)。

## 开发验证

安全回归检查已通过轻量 JUnit 入口接入 Maven Surefire。在项目根目录执行：

```powershell
mvn test
# 无桌面环境：图像分支旧测试因 Robot 构造限制明确跳过，其余适用检查继续执行。
mvn test '-Djava.awt.headless=true'
```

默认入口覆盖标准 JUnit 检查及已审查的旧测试主程序；Windows/COM 与桌面依赖会在 JUnit 中明确报告跳过。旧式检查使用独立 JVM 和 `target/test-sandboxes/` 下新建的应用目录，避免 `AppConfig` 读写个人配置；失败返回 Surefire，未发现测试时构建失败。Surefire 通过 `macro.errorReport.applicationDirectory` 显式将测试触发的错误报告隔离到 `target/test-error-reports/log/`，独立子进程使用各自的应用目录。测试报告位于 `target/surefire-reports/`，实际执行结果见 [自动测试记录](docs/automated-tests.md)。

现有独立 `main()` 入口仍然保留。会显示窗口、实际截图、注册全局钩子或等待用户操作的检查不进入默认自动运行，也不能直接在个人配置目录中批量启动。全部测试的副作用盘点、自动范围、隔离原理和人工验证边界见 [`docs/automated-tests.md`](docs/automated-tests.md)。

数字输入规则和范围见 [`docs/numeric-input-rules.md`](docs/numeric-input-rules.md)。

## 当前已知限制

- 当前只提供 Windows 原生实现；macOS/Linux 文件面板明确报不支持，没有跨平台备用界面。
- 播放时的图像匹配使用 OpenCV 模板识别，独立的 OCR 入口只提取文字；均不进行语义识别。主题、抗锯齿、遮挡及外观变化可能影响命中；缩放只在有限范围和比例中搜索，不保证识别任意缩放，尚未提供搜索区域编辑。
- 极小、纯色、低纹理或重复模板可能匹配很多位置，质量提醒不能消除歧义。识别服务最多保留 100 个结果，测试窗口显示保留结果；结果上限不等于限制扫描范围。内存数据包含进程采样和主要缓冲区估算，不是精确的原生分配追踪。
- 识别依赖当前可见桌面，不读取被遮挡、最小化或受保护窗口的隐藏画面；多显示器和混合 DPI 仅有基础实现，尚未完整验收。
- 播放仍操作真实键鼠，指定宏目标窗口时会尝试激活目标；尚未实现“不移动鼠标、不抢焦点”的后台操作模式。已讨论的被遮挡窗口后台输入及直接窗口取图只是后续方案，不属于本版已实现功能。
- 路径引用的模板不是可自动搬移的资源包；重试没有配置超时或次数上限，应确保能够停止或终止。
- 原生面板的特别长路径、网络共享及跨显示器 DPI 切换仍需实机复核；部分 UI 场景也需在 Windows 11 的 150% 缩放下人工确认。
- 软件版本由维护者修改 `ApplicationInfo.APP_VERSION`，Maven 同步数字版本并保留后缀；本版数字版本均为 `1.2.0`，`.mr` 格式版本另行管理。

仓库保留当前源码和正式资源，不包含旧源码压缩包、个人运行数据或 Windows 打包产物。
