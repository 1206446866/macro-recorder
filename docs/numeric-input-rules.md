# 数字输入盘点与规则

本文记录数字输入专项的规则及历史验证；该专项只修改 UI 输入、校验和提交入口，当时未修改录制器、播放器、识别算法、文件面板、AppConfig、MacroAction、MR 格式和版本。后续工作区变化及最新测试结果见 [文档索引](README.md)，不要将该专项范围视为整个项目当前修改范围。

## 按当前源码确认的数值输入

| 输入项 | 所在界面 | 原模型及允许范围 | 单位及默认值 |
|---|---|---|---|
| 播放循环次数 | MacroFrame | Integer Spinner，1～2147483647 | 次；默认 1。无限循环仍由复选框控制，内部 -1 不开放给输入框 |
| 鼠标移动采样间隔 | SettingsDialog | Integer Spinner，0～2147483647 | ms；默认 20；0 表示不限制采样间隔 |
| 动作延迟 | ActionEditorDialog、时间线内联编辑 | long，0～9223372036854775807 | ms；新普通动作默认 0，保留原 delay 语义 |
| 图像识别重试延迟 | ActionEditorDialog，与动作延迟共用输入框 | long，0～9223372036854775807 | ms；新图像节点默认 1000，仅成功或失败选择重试时显示；隐藏时保留此前合法值，不让临时空值阻止无重试行为的保存 |
| 图像匹配阈值 | ActionEditorDialog | Integer Spinner，1～100 | 整数百分比；默认 90；存储仍除以 100 转为小数 |
| 测试匹配阈值 | ImageRecognitionFrame | Integer Spinner，1～100 | 整数百分比；默认 90。支持载入当前图像节点的完整阈值范围 |
| 测试缩放上下限 | ImageRecognitionFrame | Double Spinner，下限 1～100、上限 100～400 | 百分比，最多三位小数；默认精确 2/3 与 1.5，显示约 66.667%～150%，仅本测试窗口使用 |
| X、Y 坐标 | ActionEditorDialog、时间线内联编辑 | int，-2147483648～2147483647 | 屏幕逻辑坐标；新动作默认 0；不新增屏幕边界限制 |
| 图像失败点击 X、Y | ActionEditorDialog 图像识别属性 | int，-2147483648～2147483647 | 固定屏幕逻辑坐标，默认留空；失败点击时两项都必填，0 和负值有效，不借用旧命中或窗口相对位置 |
| 滚轮量 | ActionEditorDialog | int，-2147483648～2147483647 | 滚轮刻度；新动作默认 1；保留正负方向，原本允许的 0 继续允许 |

按键代码是自动生成、可复制的只读显示，不是数字输入入口；按键名称、目录路径等普通文本不接入数字过滤。系统原生文件面板中的输入由操作系统管理。

## 公共机制

整数输入统一使用 `com.macro.ui.util.NumericInputUtil`。识别测试窗口新增的缩放百分比是独立的小数输入，使用严格格式化器检查整段文本、范围及三位小数；Enter、箭头提交和开始识别均不能把非法文本截取为合法数值。未改动的默认下限保留精确 2/3，避免显示舍入改变默认比例；失焦保留待提交文本，关闭缩放时禁用且不校验上下限，不影响原有整数规则。

- `DocumentFilter` 对整个编辑结果检查字符格式：ASCII 数字；有符号字段允许开头的 `-`。非法键入或粘贴整体拒绝，不截取其中的数字。
- 整数输入不接受小数、科学计数法、分组逗号、正号、空格和非数字字符；新增测试缩放百分比按上文的小数规则处理。
- 编辑过程中允许空值；有符号字段还允许暂时只保留负号。范围及溢出在失焦或提交时校验，不限制中途输入数值的大小。
- Spinner 保留既有 `SpinnerNumberModel`、范围、步长及默认值；通过整数格式化器提交。过滤器与原格式化器协作，保留光标、编辑状态和 Enter 行为。
- 失焦有效则校验/提交；无效则保留文本，以现有主题危险色边框和悬停提示标记，不弹窗、不抢回焦点。
- 播放、设置保存、节点保存、开始识别前再次检查并提交当前文本；空值、越界或溢出阻止继续操作，使用已有消息组件显示明确字段说明。
- 时间线内联编辑失败保留编辑器及原动作；修正后可重新提交，Esc 仍取消。

## 验证范围

- 工具测试直接操作真实 Swing 文档、TransferHandler、格式化器及组件动作，覆盖非法字符、粘贴、全选替换、退格/Delete、临时空值、负号、小数、int/long 边界与溢出。
- 检查 Spinner 失焦、Enter、原格式化器提交、箭头递增以及通过代码设置值后过滤器仍然有效；无效输入不更新模型。
- 编辑器测试通过实际保存按钮检查负坐标、负滚轮量、延迟和未提交阈值；按键名称编辑及只读代码同步正常。
- 时间线测试检查空值/溢出不修改原动作，合法值恢复提交，Esc 取消仍然生效。
- 设置测试将测试对象的配置目录定向到 target 内临时目录，通过真实保存入口写入配置并重新加载；同时检查项目用户配置文件字节未改变。
- 对编辑后的普通动作与图像节点执行 MR 保存/重载，确认坐标、方向、毫秒值、阈值及普通 MR 读写兼容。

仍需人工复核真实键盘和输入法、Ctrl+V、Tab/鼠标切换焦点、错误边框/悬停提示在 150% 缩放下的显示，以及实际播放/识别入口的错误提示。自动测试没有发送真实键鼠输入，也没有执行宏播放或实际图像识别。
