## 已讨论、尚未实现

后台操作模式的拟定范围：未指定窗口时沿用现有操作；指定窗口时，目标是窗口保持正常展开、即使被其他窗口遮挡，也能接收操作，不移动真实鼠标、不抢焦点，并直接获取该窗口画面。后台输入和窗口取图需要分别验证目标软件的兼容性，最小化暂不作为保证范围。

当前仍使用真实键鼠及可见屏幕截图，指定窗口识别要求前台且未最小化。上述方案尚未编写实现，也未纳入更新日志的已完成功能。
