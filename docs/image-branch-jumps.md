# 图像分支指定节点跳转与时间线连接（2026-10-20）

当前说明同步于 2026-10-21，包含后续编号、禁用样式、端口位置及保存校验修复。初始实现与后续测试结果分别标注；项目总览见 [文档索引](README.md)。

## 实现与兼容性

成功、失败行为各自新增“跳转到指定节点”，从当前时间线按“序号 · 操作名称”选择，无需输入ID。允许指向更早或更后的普通/图像节点，两种结果可以不同，也可以相同；自身使用原“重试”，内部END使用原“终止”。未指定、被删除的目标不会自动替换为附近节点。

继续使用现有 `MacroBranch.targetId`，没有添加重复的目标字段、伪流程节点或图像输入 ActionType。`ImageCheckBehavior` 新增JUMP；旧三种枚举含义、MR版本、字段结构和旧文件默认行为均保留。旧文件在当前版本继续可读；含JUMP的新宏需要支持该新行为的应用版本，不能承诺旧程序理解新枚举。

时间线插入、删除、替换引发重建时，仅默认EXECUTE按显示后继重接；JUMP保留实际分支目标ID及已有分支延迟，重试仍为自身且使用原重试延迟。播放器原先就按ID跳转，本次不改播放循环架构，只扩展预检到JUMP。实际执行顺序来自图，不来自显示顺序。新编辑器创建的指定跳转分支等待为0，不把重试延迟套给指定跳转。

预检继续检查所有引用与必需分支；指定跳转拒绝缺失、END、自身目标，以及无法到达END/终止或明确重试行为的闭环。该检查在进入播放状态、识别和输入前运行，MR 加载与保存也使用现有结构校验及跳转检查。允许有退出路径的前后跳转循环；明确的旧重试仍可无限等待匹配，不新增次数/时间限制。识别结果长期固定仍可能使有理论退出分支的循环持续执行，沿用原暂停/停止能力，不声称能静态预测识别结果。

## 显示编号与目标菜单

`TimelineNodeNumbers` 按当前真实节点顺序生成 `01`、`02` 等编号，不计内部 END，超过 99 后继续显示 100、101。卡片徽标、成功/失败目标菜单及远距离标签复用同一计算方式；菜单排除当前节点，但保留该节点在整体顺序中占用的编号。插入、删除、重排和刷新时重新计算，仅展示，不改节点 ID 或 `MacroBranch.targetId`。

编号在 `NodePanel.paintChildren` 后叠加绘制，采用现有主题色，不增加组件、边距或布局占位；卡片继续固定 158×176，原图标、标题、参数、坐标及连接器布局不移动。选中只改变徽标颜色。

成功/失败目标仅由各自行为控制启用，只有 JUMP 可选。`ComponentStyleUtil` 修复 BasicComboBoxUI 在禁用时用 LAF 浅色默认值覆盖渲染器的原因，直接使用主题深色背景、弱化文字、边框和箭头；启用仍走原正常绘制，不降低整个组件透明度，不修改保存或播放语义。

## 连线

`TimelineTrackPanel` 每次按当前 NodePanel 的ID与边界计算路径，目标来自有效分支引用。前跳使用主题强调色，从目标左侧以水平向右箭头进入；回跳使用主题危险色，从目标右侧以水平向左箭头进入。指定相邻目标也采用独立轨道。原始EXECUTE数据若已有非相邻实际引用，也按真实引用画远距离线，不再错误画向显示后继的默认箭头。

每条远距离分支占用独立的下方轨道，目标共享时分配不同端口；标签避开穿过该轨道的竖线，必要时短引线连接标签位置，标签在路径后统一绘制。原重试自回路、延迟文字、默认后继与终止标记保留。轨道高度按分支数增长，启用必要的纵向滚动；原有横向滚动保留。删除目标后旧连线不残留，原引用继续保留为无效以供编辑器提示和预检拒绝，不静默重定向。

2026-10-21 连线样式及端口微调：每条分支的发线、收线同高且水平引线等长。端口位于顺序线下方、重试端口上方，常规布局为两边预留至少 8 逻辑像素；有主链箭头时读取其实际中心高度，无箭头时使用布局基准。多个分支在端口带内分配位置，同侧入/出线共用端口占用表，分离竖段；下方轨道间距保持 32。圆角最大半径为 12，与重试回路一致，去掉起点圆点；交叉处使用细断口区分路径，标签使用深色描边胶囊。前跳/回跳颜色与真实目标身份不变。

## 保存完整性

`MacroStorage.save` 对非 null flow 先调用与 load 相同的 `validateFlow(flow)`，在创建目标目录、临时文件和替换正式文件前完成。删除被引用目标后，即使时间线已不画失效连线，保存仍抛出带节点信息的 `IllegalArgumentException`，由主窗口原保存失败处理接收；不自动转到下一个节点，原有效 MR 不被覆盖。当前状态栏沿用通用保存失败提示，具体异常写入原日志。

该校验只要求模板路径非空，不要求图片实际存在。非空缺失模板引用、旧版 null flow 动作列表入口继续兼容；实际播放的模板可用性另由原播放预检处理。MR 格式、字段和原子写入/清理流程不变。

## Windows 11、150% DPI 人工验收

1. 成功跳到后方释放卡并跳过中间动作，失败回到前方释放卡后沿流程执行；分别测试不同目标与同一目标。
2. 验证重试延迟、自回路、默认后继与整任务终止未变；暂停/停止能打断明确配置的循环。
3. 前跳箭头从目标左侧水平进入，回跳从右侧水平进入；相邻/远距离目标、多条分支和多个图像卡共存时标签可辨认。
4. 检查纵向滚动能访问全部下方轨道，横向滚动、较窄窗口与150%DPI下文字/箭头不裁切；线条交叉处仍需可见桌面确认辨识度。
5. 插入、删除、替换及重新加载后目标仍按身份连接；删除目标时无旧连线，编辑器提示失效，保存被拒绝且原 MR 不变，播放在输入前明确拒绝。
6. 新编辑器在150%DPI下完整显示成功/失败行为与目标行，取消不改变数据，保存再打开能回显目标。
7. 编号不遮挡原内容，插入/删除/重排后与两个目标菜单及标签一致；禁用目标菜单无白底，两个结果独立启用/禁用。
8. 发线与收线同高，位于顺序线下方、重试端口上方；圆角与重试回路协调，多分支、相邻目标及滚动时均清晰可辨。

本轮未进行真实匹配/键鼠桌面播放验收；最终以用户实际界面与执行行为确认。
