# 图像分支指定节点跳转与时间线连接（2026-10-20）

当前说明同步于 2026-10-28，包含编号、端口位置、保存校验、识别后点击、拖动排序、编辑字段按需显示与撤销。初始实现与后续测试结果分别标注；项目总览见 [文档索引](README.md)。

## 识别成功后点击（2026-10-26，1.2.0）

正式播放的识图已增加内存位置提示，执行到节点才局扫；局扫失败后竞速扩大局扫和全扫，先命中的阶段返回，未收尾任务占用配额时串行回退。成功点击使用获胜阶段中相似度最高的当前命中，多个相同目标不保证选择最近者；缓存坐标仅用于定位搜索范围，不能直接用于点击。无提示时首次执行全扫，加载 MR 和播放预检不截图；阶段范围及失效条件见 [按位置优先识别](../README.md#按位置优先识别)。

成功和失败行为均提供“点击后执行”（CLICK_EXECUTE）和“点击后终止”（CLICK_TERMINATE），两个菜单选项与顺序相同，跳转始终最后。成功点击使用本次识别的最佳命中区域，失败点击使用独立配置的固定屏幕 X/Y 坐标，均执行一次鼠标左键按下、释放，再分别继续后继或退出整个任务；终止包含无限循环，不会点击后进入下一轮。

`ImageCheckConfig.failureClickX/failureClickY` 为可空 Integer，旧 MR 缺省为空；失败点击时必须两者完整，允许 0 和负数，保存/加载/播放预检共用校验，另存为保留。坐标不按识别窗口相对换算，不读取上次成功范围、模板采集位置或局扫提示；只在真正 NOT_FOUND 时执行，识别异常不转为失败点击。未选择失败点击时，旧宏失败逻辑不变，已填合法坐标可保留。编辑器新增两项坐标输入并将图像编辑高度从 540 调整为 580。

图像动作可单独配置[窗口内识别](window-recognition.md)：所有搜索阶段均限定在当前客户区，命中仍返回全局逻辑坐标供上述点击使用；DPI 换算后的点击框约束在本次截图范围内。窗口不可用或失效属于运行错误，不触发普通未找到分支，不使用旧命中或桌面结果代替。旧 MR 默认桌面模式。

仅在成功选择点击行为时显示“点击方式”。CENTER 为中心点击，RANDOM 为范围内随机点击；随机坐标不包含矩形右/下边界，支持负坐标和 1×1 逻辑区域。使用实际命中区域，因此缩放匹配后跟随实际大小，不再按模板原尺寸计算。`ImageCheckConfig.clickMode` 保存到 MR，缺省或 null 使用 CENTER，另存为路径转换时保留；失败点击独立使用固定坐标，其他原有行为不增加点击，测试识别窗口也不发送输入。

行为下拉框通过统一选项生成函数将 JUMP 稳定排在最后，不依赖枚举声明顺序；以后新增选项也沿用该规则。时间线重建、默认主链、终止标记和跳转闭环检查均将两种点击行为分别按 EXECUTE/TERMINATE 的流程语义处理，不新建伪动作节点，不把点击混入兼容 actions 列表。

暂停/停止在移动前、按下前及完成点击后检查；鼠标已按下时先完成释放，再响应暂停/停止。按下或释放异常沿用播放器跟踪及最终释放逻辑，避免跳过清理。点击后执行仍完整等待后续动作间隔；不新增固定点击延迟。实际 Windows 11、150% DPI 下的识别后点击位置、随机范围、目标窗口响应、F11/F12 与停止恢复仍需人工验收，自动化只使用计数 Robot、合成结果和不显示的编辑器。测试结果见自动测试记录。

## 实现与兼容性

成功、失败行为各自新增“跳转到指定节点”，从当前时间线按“序号 · 操作名称”选择，无需输入ID。允许指向更早或更后的普通/图像节点，两种结果可以不同，也可以相同；自身使用原“重试”，内部END使用原“终止”。未指定、被删除的目标不会自动替换为附近节点。

继续使用现有 `MacroBranch.targetId`，没有添加重复的目标字段、伪流程节点或图像输入 ActionType。指定跳转实现新增 JUMP；旧三种枚举含义、MR版本、原有字段含义和旧文件默认行为均保留。旧文件在当前版本继续可读；含JUMP的新宏需要支持该新行为的应用版本，不能承诺旧程序理解新枚举。新增点击方式字段及默认值见上方后续实现说明。

时间线插入、删除、替换引发重建时，仅默认EXECUTE按显示后继重接；JUMP保留实际分支目标ID及已有分支延迟，重试仍为自身且使用原重试延迟。播放器原先就按ID跳转，本次不改播放循环架构，只扩展预检到JUMP。实际执行顺序来自图，不来自显示顺序。新编辑器创建的指定跳转分支等待为0，不把重试延迟套给指定跳转。

预检继续检查所有引用与必需分支；指定跳转拒绝缺失、END、自身目标，以及无法到达END/终止或明确重试行为的闭环。该检查在进入播放状态、识别和输入前运行，MR 加载与保存也使用现有结构校验及跳转检查。允许有退出路径的前后跳转循环；明确的旧重试仍可无限等待匹配，不新增次数/时间限制。识别结果长期固定仍可能使有理论退出分支的循环持续执行，沿用原暂停/停止能力，不声称能静态预测识别结果。

## 显示编号与目标菜单

`TimelineNodeNumbers` 按当前真实节点顺序生成 `01`、`02` 等编号，不计内部 END，超过 99 后继续显示 100、101。卡片徽标、成功/失败目标菜单及远距离标签复用同一计算方式；菜单排除当前节点，但保留该节点在整体顺序中占用的编号。插入、删除、重排和刷新时重新计算，仅展示，不改节点 ID 或 `MacroBranch.targetId`。

编号在 `NodePanel.paintChildren` 后叠加绘制，采用现有主题色，不增加组件、边距或布局占位；卡片继续固定 158×176，原图标、标题、参数、坐标及连接器布局不移动。选中只改变徽标颜色。

成功/失败目标仅在各自选择 JUMP 时显示；成功点击方式、失败 X/Y、重试延迟、指定窗口按钮也依据当前选项显示，连同标签一起隐藏。隐藏不移除控件或清空编辑值，整排隐藏后重新排列下方字段；原左右配对保持，避免成功/失败或 X/Y 错列。窗口大小保持 580，不因切换选项反复调整。

隐藏的重试延迟不用作当前行为时，临时空值或非法文本不会阻止保存，保留此前合法值；重新选择重试后依旧使用原数值校验。切回普通输入动作会恢复共用延迟框的显示与启用状态。未修改播放器、存储或 MR 格式。

历史禁用样式修复仍保留在 `ComponentStyleUtil`：避免 BasicComboBoxUI 使用浅色 LAF 默认值，禁用控件仍用主题色，不降低整个组件透明度。当前相关目标菜单按需隐藏，该公共样式仍供其他禁用下拉框使用。

## 查找节点

`TimelineNodeSearch` 提供局部查找栏与纯参数匹配。Ctrl+F 打开，按当前展示编号精确定位（可加 #、前导零），或按动作类型、按键名称/左右侧及图片文件名查找；文字规范化全角、忽略大小写，多个词须全部命中。单个英文字母按独立名称匹配，避免误命中其他英文类型名。使用已保存按键名、当前系统显示名和缓存的公开按键常量名称；模板只查文件名，不把父目录或隐藏节点 ID 当作内容。不读取文件、不做 OCR 或屏幕匹配。

输入及前后切换时，以独立金色外框标出当前结果，并在布局完成后滚动到卡片；Enter/F3 下一项，Shift+Enter/Shift+F3 上一项，结果循环。全部卡片与原多选保留，查找不调用流程修改回调、不增加撤销步骤，也不改分支。空结果显示“无匹配”并禁用前后按钮。

查找范围仅当前时间线的普通动作和图像节点，不包含待机头与 END。录制、播放和暂停查看可用；搜索框仍使用文字复制/粘贴/全选/删除。Esc 优先关闭查找而不清多选，关闭后重开保留查询；外部 setFlow 换宏清空查询，撤销保留查询。所有重建刷新结果但不自动滚动，旧结果被删时去除高亮，编号查询按新顺序重新匹配。通过导航与时间线版本双重校验丢弃过时的延迟滚动，避免关闭/换宏/继续输入后跳到旧位置。打开查找会取消尚未提交的行内编辑及拖动预览，不写回旧编辑值。

## 节点复制／粘贴

Ctrl+C 复制选中节点，Ctrl+V 固定插入到选中节点后，无锚点则追加。节点在复制时序列化为独立快照，每次粘贴重新解析，再由时间线统一分配新 ID、重接默认分支并记入一步撤销；所有原图像参数与动作数据保留。复制不修改模型，也不占撤销步骤；只读查看可复制，粘贴仍受录制/播放与迟到回调保护。文字输入框不触发时间线快捷键。

复制图像节点时，JUMP 保留原目标 ID 及分支等待；目标不存在或指向 END 时拒绝粘贴，不按显示编号猜测。RETRY 重接副本自身，EXECUTE 使用新后继，TERMINATE 使用当前宏 END。复制本身不搬移模板：同目录保留原相对引用，跨目录按复制时的 MR 基准转换为原文件绝对路径，即使来源文件缺失也不误指目标目录同名图片。源节点移动、修改或删除后，剪贴板快照仍独立存在，直到被其他内容替换。

多选复制按时间线原顺序保存一组独立快照，剪贴板使用版本 2；单节点继续使用版本 1。粘贴先校验整组，生成全部新 ID 后，将组内 JUMP 目标映射到相应副本；组外 JUMP 沿用原 ID，任一外部目标缺失或不合法则整组拒绝。只重接默认后继及 RETRY/TERMINATE，保留动作、图像配置和指定跳转等待。新节点整体选中，一次通知、一次撤销；总剪贴板数据仍限制为 1 MiB。MR 文件格式不变。

## 多选与批量编辑

Ctrl 点选切换单项，Shift 从上次普通/Ctrl 点击的锚点连选，Ctrl+Shift 追加区间；Ctrl+A 全选，不包含待机头及 END。单击其他卡片只选择该项，点击已选卡片在释放时才收拢选择，因此按住并拖动可以保留整组。空白单击及 Esc 清空选择；输入框保留文字快捷键，坐标区域的 Ctrl/Shift 点击仅选择、不开始编辑。

选择集合保存节点 ID，并另外保留当前主选中节点和区间锚点。批量编辑面板只提交勾选字段，普通动作 delay 与图像节点 retryDelay 分开；图像间隔只写入具有 RETRY 行为的节点，不更改其他识别行为或延迟。无效输入、旧节点、权限丢失均拒绝，无变化不占历史。没有适用延迟的图像组合禁用批量编辑，移动/复制/删除仍可用。

整组拖动保留原相对顺序，不连续选择聚为一组；预览复用原组件，不写流程。影像显示组内数量，所有目标槽位均有占位。提交时统一重建默认分支并保留原 ID，指定跳转和被指向节点身份不变，延迟随节点移动。删除所选只确认一次且不合并延迟，剩余节点的失效指定引用不自动重定向；确认中提示这些引用需重新指定，保存/播放沿用现有预检拒绝。

每批编辑、移动、删除或粘贴只保存一次流程快照、发送一次主窗口变更通知，撤销恢复完整选择、主节点和锚点。打开批量弹窗/确认或旧菜单后，若流程版本或权限已改变，不接收过时结果。录制、播放及暂停时仍可多选、查看和复制，所有写入入口使用同一编辑权限检查。

## 时间线撤销

空闲时间线内使用 Ctrl+Z 或右键菜单撤销最近一次确认修改。完整流程快照保留节点 ID、顺序、END、各分支及延迟、图像配置和选择；撤销直接恢复快照，不重新推算或改指跳转目标。删除目标导致的暂时无效引用也可以撤销恢复，删除时保留给后项的延迟一起还原。拖动预览、取消及无变化操作不写入历史。

历史仅内存保存，最多 100 步，约 32 MiB 以上优先淘汰更早记录，单个超大快照仍保留最近一步；模板图片不进入快照。不支持重做。录制、播放和暂停时沿用现有编辑保护，文字输入框不触发时间线撤销。撤销会使旧行内会话、弹窗及确认回调失效，通过主窗口回调同步播放和保存使用的流程，并关闭旧对象的编辑器。加载或录制新宏以及跨目录另存为清空历史；同目录保存保留历史，撤销不自动改写磁盘文件。

## 拖动排序

空闲时可拖动 ACTION 和 IMAGE_CHECK 卡片，头部待机卡及内部 END 不参与排序。按下后移动至少 6 个逻辑像素开始拖动，坐标编辑区域保持原单击编辑；双击、选择及右键菜单保留。影像以当前显示 DPI 离屏绘制一次，再轻微模糊并半透明显示，按下位置与鼠标之间的偏移保持不变。

预览通过复用卡片组件、重排视图和重建相邻延迟连接器显示占位，不改 `MacroFlow`、节点列表或分支引用。槽位使用拖动开始时布局的中心分界，避免占位移动反复改变判定边界而抖动；靠近视口左右 36 个逻辑像素内，以 40ms 定时逐步滚动。占位文字显示预计落位编号，已有卡片编号在松手提交时统一刷新；预览连线的前跳/回跳文字依据当前卡片位置显示，分支目标 ID 始终保留。

释放在轨道视口内才调用 `moveNode`，保留原节点对象及 ID，并复用 `MacroFlowFactory.rebuildLinear` 重接普通默认后继：EXECUTE/CLICK_EXECUTE 指向新后项，RETRY 指向自身，TERMINATE/CLICK_TERMINATE 指向 END，JUMP 保留原目标 ID 及跳转分支延迟。动作 delay 随动作对象移动，头部等待及 END 身份保留。多个入向分支和被拖动图像节点的出向指定跳转都按身份保留，显示编号改变不重定向目标；新顺序通过既有流程变更回调同步到主窗口及已打开的节点编辑器。

Esc、轨道外释放、窗口失去激活、面板隐藏/移除、时间线重建/换宏、编辑权限丢失均取消；每次释放和取消移除临时事件监听、停止自动滚动并释放影像。录制、播放、暂停和停止收尾期间沿用既有编辑保护，实际写入前再次检查权限。只拖回原位不发出流程修改通知。MR 使用既有有序节点索引及 ID 引用保存，不增加拖动字段或修改格式版本。

## 连线

仅图像识别出向及进入图像节点的相邻连接器显示上方行为/条件：普通动作进入图像节点显示“执行”，图像默认后继保留“识别成功”“未找到”或合并条件；普通动作之间只保留延迟和箭头。目标为图像节点时读取实际入向分支的等待，替代旧“检查”占位；当前工厂生成的这类分支为 `0 ms`。旧流程含非零入向分支等待时按原值显示，图像成功/失败共用后继但等待不同时按成功、失败顺序分别列出，悬浮提示说明对应条件。下方自回路时间仍单独表示重试间隔，播放、编辑和存储语义不变。

`TimelineTrackPanel` 每次按当前 NodePanel 的ID与边界计算路径，目标来自有效分支引用。前跳使用主题强调色，从目标左侧以水平向右箭头进入；回跳使用主题危险色，从目标右侧以水平向左箭头进入。指定相邻目标也采用独立轨道。原始EXECUTE数据若已有非相邻实际引用，也按真实引用画远距离线，不再错误画向显示后继的默认箭头。

每条远距离分支占用独立的下方轨道，目标共享时分配不同端口；标签避开穿过该轨道的竖线，必要时短引线连接标签位置，标签在路径后统一绘制。原重试自回路、延迟文字、默认后继与终止标记保留。轨道高度按分支数增长，启用必要的纵向滚动；原有横向滚动保留。删除目标后旧连线不残留，原引用继续保留为无效以供编辑器提示和预检拒绝，不静默重定向。

2026-10-21 连线样式及端口微调：每条分支的发线、收线同高且水平引线等长。端口位于顺序线下方、重试端口上方，常规布局为两边预留至少 8 逻辑像素；有主链箭头时读取其实际中心高度，无箭头时使用布局基准。多个分支在端口带内分配位置，同侧入/出线共用端口占用表，分离竖段；下方轨道间距保持 32。圆角最大半径为 12，与重试回路一致，去掉起点圆点；交叉处使用细断口区分路径，标签使用深色描边胶囊。前跳/回跳颜色与真实目标身份不变。

## 保存完整性

`MacroStorage.save` 对非 null flow 先调用与 load 相同的 `validateFlow(flow)`，在创建目标目录、临时文件和替换正式文件前完成。删除被引用目标后，即使时间线已不画失效连线，保存仍抛出带节点信息的 `IllegalArgumentException`，由主窗口原保存失败处理接收；不自动转到下一个节点，原有效 MR 不被覆盖。当前状态栏沿用通用保存失败提示，具体异常写入原日志。

该校验只要求模板路径非空，不要求图片实际存在。非空缺失模板引用、旧版 null flow 动作列表入口继续兼容；实际播放的模板可用性另由原播放预检处理。MR 格式版本和原子写入/清理流程不变。

## Windows 11、150% DPI 人工验收

1. 成功跳到后方释放卡并跳过中间动作，失败回到前方释放卡后沿流程执行；分别测试不同目标与同一目标。
2. 验证重试延迟、自回路、默认后继与整任务终止未变；暂停/停止能打断明确配置的循环。
3. 前跳箭头从目标左侧水平进入，回跳从右侧水平进入；相邻/远距离目标、多条分支和多个图像卡共存时标签可辨认。
4. 检查纵向滚动能访问全部下方轨道，横向滚动、较窄窗口与150%DPI下文字/箭头不裁切；线条交叉处仍需可见桌面确认辨识度。
5. 插入、删除、替换及重新加载后目标仍按身份连接；删除目标时无旧连线，编辑器提示失效，保存被拒绝且原 MR 不变，播放在输入前明确拒绝。
6. 新编辑器在150%DPI下完整显示成功/失败行为与目标行，取消不改变数据，保存再打开能回显目标。
7. 编号不遮挡原内容，插入/删除/重排后与两个目标菜单及标签一致；禁用目标菜单无白底，两个结果独立启用/禁用。
8. 发线与收线同高，位于顺序线下方、重试端口上方；圆角与重试回路协调，多分支、相邻目标及滚动时均清晰可辨。
